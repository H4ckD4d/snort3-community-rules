# Security and Responsible Use

> **Project owner and original creator: Chris Cruz | h4ckd4d**

This repository contains defensive detection content for systems and networks you own, administer, or are explicitly authorized to monitor.

## Intended use

Appropriate uses include:

- SOC and Blue Team engineering;
- IDS/IPS rule development;
- SIEM detection development;
- defensive lab validation;
- alert tuning and false-positive analysis;
- security education using synthetic data.

## Prohibited repository content

Do not publish credentials, personal data, victim data, private infrastructure details, or weaponized malicious material in issues, pull requests, fixtures, or rule comments.

## Detection limitations

A detection alert is evidence that configured conditions matched telemetry. It is not automatically proof of compromise, attribution, intent, or successful exploitation.

Analysts should preserve the distinction:

> **Telemetry match ≠ confirmed incident**

## Reporting repository issues

Use GitHub issues for unsafe examples, broken validation, incorrect metadata, syntax problems, or false-positive concerns. Do not post sensitive third-party data publicly.
